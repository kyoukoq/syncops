# SyncOps v0.2.0 release decision

The Product Owner explicitly accepted the documented residual risks on **2026-11-25** and authorized stable publication of source commit `2884aeb5c8b72610754b430b799046be43f33825` with the two artifacts below. The next review is due by **2026-12-02**, or earlier if a relevant advisory, deployed digest, or exposure changes. [Security risk register](../security-risk-register.md)

## Accepted scope

- Local, self-hosted engineering laboratory on a single Windows and WSL2 host.
- Synthetic demonstration data and trusted local users.
- Loopback-only access for personal portfolio and educational demonstrations.

The approval excludes public internet exposure, corporate production deployment, real customer data processing, and multi-tenant usage. The residual risks include the Alpine and native Windows SQLite runtimes, the private libpq and OpenSSL copies bundled by Psycopg, the single-host trust boundary, and scan coverage limited to the two Linux amd64 project images. Live HTTPS Ingress was not run, and visual acceptance of the native SQLite console remains unverified. [Local acceptance](../local-acceptance.md)
