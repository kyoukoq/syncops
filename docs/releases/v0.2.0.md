# SyncOps v0.2.0 release decision

The Product Owner explicitly accepted the documented residual risks on **2026-11-25** and authorized stable publication of source commit `2884aeb5c8b72610754b430b799046be43f33825` with the two artifacts below. The next review is due by **2026-12-02**, or earlier if a relevant advisory, deployed digest, or exposure changes. [Security risk register](../security-risk-register.md)

## Accepted scope

- Local, self-hosted engineering laboratory on a single Windows and WSL2 host.
- Synthetic demonstration data and trusted local users.
- Loopback-only access for personal portfolio and educational demonstrations.

The approval excludes public internet exposure, corporate production deployment, real customer data processing, and multi-tenant usage. The residual risks include the Alpine and native Windows SQLite runtimes, the private libpq and OpenSSL copies bundled by Psycopg, the single-host trust boundary, and scan coverage limited to the two Linux amd64 project images. Live HTTPS Ingress was not run, and visual acceptance of the native SQLite console remains unverified. [Local acceptance](../local-acceptance.md)

## Publication

Both public stable tags were verified anonymously before the GitHub release existed. Each stable tag, corresponding candidate tag, and direct digest reference returned identical manifest bytes. The promotion job copied the original registry manifests without an image build. Independent verification of the stable references passed for both SLSA provenance and CycloneDX SBOM. [Prepublication promotion](https://github.com/kyoukoq/syncops/actions/runs/45629642563)

The stable GitHub release was published at `2026-11-25T14:03:24Z`. The remote annotated Git tag peels to the approved commit, and the stable image tags retained the same manifests after publication. The release-triggered promotion job passed with the build and candidate publication jobs skipped. [GitHub release](https://github.com/kyoukoq/syncops/releases/tag/v0.2.0) · [Postpublication workflow](https://github.com/kyoukoq/syncops/actions/runs/45629911705)

Independent local checks before and after publication confirmed the same digest-pinned containers and PostgreSQL volume. Full-row fingerprints matched for 81 events, 98 attempts, 146 audit entries, 75 simulator operations, and 8 integrations. The native SQLite database, WAL, and SHM also had identical SHA-256 hashes. The console, Grafana, Prometheus, and Alertmanager returned HTTP 200 from Windows loopback, and OpenAPI reported version `0.2.0`. No application redeployment was needed for stable tag publication.

Additional expenditure was $0. Promotion used a standard GitHub-hosted runner for the public repository and the existing public GHCR packages.
